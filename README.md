## 📌 Project Overview

**Network Port Scanning & Security Analysis** is a practical cybersecurity project designed to perform authorized network reconnaissance, TCP port scanning, service identification and basic security risk analysis.

The project combines **Nmap**, **Python**, **FastAPI** and **React** to create an end-to-end security analysis workflow.

Instead of displaying raw Nmap output only, the system processes the scan results and converts them into structured information that can be presented through an interactive cybersecurity dashboard.

### The system analyzes:

- 🔎 Network availability
- 🌐 TCP ports
- 🚪 Open / Closed / Filtered states
- 🔍 Running services
- 🧩 Service versions
- ⚠️ Security review priorities
- 🛡️ Security findings
- ✅ Security recommendations
- 📊 Security analytics
- 📄 Structured reports

# 🎯 Project Objectives

The primary objectives of this project are:

- Perform network discovery
- Identify accessible TCP ports
- Determine port states
- Detect running services
- Detect available service versions
- Perform basic port-level security analysis
- Identify potential security risks
- Generate security recommendations
- Visualize security information through a dashboard
- Generate structured security reports
- Demonstrate an end-to-end cybersecurity automation workflow

# ⭐ Key Features

| Feature | Description |
|---|---|
| 🔎 Network Discovery | Detect whether an authorized target is reachable |
| 🌐 Port Scanning | Scan common and full TCP port ranges |
| 🚪 Port State Detection | Identify open, closed and filtered ports |
| 🔍 Service Detection | Identify services running on detected ports |
| 🧩 Version Detection | Identify available service/product version information |
| 📊 Port Analysis | Analyze ports using Python |
| ⚠️ Risk Engine | Categorize security review priorities |
| 🛡️ Findings | Generate structured security findings |
| ✅ Recommendations | Provide service-specific security recommendations |
| ⚡ REST API | Expose analysis results through FastAPI |
| 🖥️ Dashboard | Visualize results using React |
| 📄 Reporting | Store scan results and security analysis |
